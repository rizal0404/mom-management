# MOM-010 — Kelola Pengguna ADMIN

Tanggal: 23 September 2026

## Perubahan

- Route `/users` dan menu sidebar hanya untuk profil `ADMIN`; member yang membuka URL langsung diarahkan ke dashboard.
- Edge Function `manage-users` mengautentikasi JWT, memeriksa profil admin aktif, lalu menangani direktori berhalaman, pembuatan akun, dan perubahan nama/peran/status.
- Service-role key hanya dibaca di Edge Function. Password sementara divalidasi minimal 12 karakter, tidak dicatat, dan tidak pernah dikembalikan setelah pembuatan akun.
- Migration menambah audit append-only `user_admin_audit` dan dua fungsi database khusus service role untuk menulis profile/audit secara atomik.
- Admin tidak dapat mengubah peran/status diri sendiri atau menghapus administrator aktif terakhir. Penghapusan akun tidak tersedia agar referensi operasional tetap utuh.
