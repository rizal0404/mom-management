# QA visual MOM-008 — 2026-09-22

Lingkup: dashboard, form notula, dan tracker tindak lanjut pada aplikasi lokal dengan fixture berlabel **DATA DEMO**. Pengujian dilakukan pada browser nyata; viewport override dikembalikan ke ukuran semula setelah pemeriksaan.

Referensi visual: Material 3 color roles dan adaptive layout, diterapkan dengan palet hijau-lime dari gambar pengguna; bukan menyalin logo/nama/data pada gambar.

## Hasil browser

| Halaman | 1440 px | 1024 px | 390 px | Catatan |
|---|---|---|---|---|
| Dashboard | PASS | PASS | PASS | Ringkasan, kartu tautan, daftar tindak lanjut aktif, dan rapat terbaru terbaca; `scrollWidth` tidak melebihi `clientWidth`. |
| Form notula draf | PASS | PASS | PASS | Label, input, agenda, PIC, jadwal, dan tombol tetap terjangkau; tidak ada overflow halaman. |
| Tracker | PASS | PASS | PASS | Toolbar filter responsif; tabel desktop tetap utuh, ponsel beralih ke kartu action tanpa overflow halaman. |

Snapshot browser diperiksa untuk dashboard desktop dan tracker ponsel. Pada 390 px, browser melaporkan lebar konten 375 px dan `scrollWidth` 375 px (tanpa overflow); perbedaan berasal dari area scrollbar/browser, bukan lebar layout aplikasi.

## Perilaku yang diperiksa

- Dashboard memuat fixture: 10 tindak lanjut aktif, 0 terlambat, 10 deadline dekat, dan 0% selesai. Nilai berasal dari query berotorisasi, bukan konstanta UI.
- Kartu **Tindak lanjut aktif** membuka `/actions?active=true`; tracker menunjukkan checkbox aktif terpilih dan hasil hanya action nonterminal.
- Loading skeleton dashboard tampil sebelum query selesai. State empty/error juga teruji pada `DashboardPage.test.tsx`; injeksi kegagalan jaringan untuk menampilkannya pada browser tidak dilakukan pada sesi ini.
- Konsol browser: tidak ada `error` atau `warn` pada sesi pemeriksaan.
- Setelah update visual lanjutan, dashboard desktop/mobile menampilkan surface tonal hijau-lime, hero shape dekoratif, typography hierarchy, tombol pill, selected navigation container, serta kartu extra-large yang konsisten dengan arah M3.

## Batasan

UAT pengguna dan E2E lintas pengguna tetap belum dijalankan; keduanya merupakan gate MOM-009, bukan bukti browser MOM-008 ini.
