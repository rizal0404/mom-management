## Temuan UAT

- **F-01 — identitas PIC/aktor nonaktif tidak terwakili konsisten.** Setelah UAT-07 menonaktifkan akun MEMBER, detail notula FINAL menunjukkan `PIC: Belum tersedia`, tracker menunjukkan `PIC tidak tersedia`, dan riwayat action menunjukkan `Pengguna tidak tersedia`. Dropdown PIC di detail action menampilkan ADMIN aktif sebagai nilai pilihan, bukan label PIC nonaktif. Ini bukti masalah tampilan/resolusi nama, **bukan bukti bahwa assignment database berubah**; akses cloud yang dipakai untuk UAT tidak memiliki kueri baca langsung untuk memastikan nilai UUID tersimpan. Source memakai roster profil aktif di detail notula/action dan fallback label pada tracker/audit (`src/modules/meetings/meetingService.ts`, `FinalMeetingView.tsx`, `src/modules/actions/actionService.ts`, `ActionDetailPage.tsx`). Jangan aktifkan akun kembali hanya untuk menyamarkan temuan. Perbaiki penampilan nama historis tanpa membuka profil nonaktif kepada anggota, dan pastikan form tidak memberi kesan bahwa assignment berubah.
