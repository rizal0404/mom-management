# MOM-005 A01 — finalisasi hanya dari draf tersimpan, 22 September 2026

## Perbaikan

Editor notula sekarang memeriksa perubahan lokal sebelum membuka dialog finalisasi. Jika draf kotor, aplikasi menampilkan pesan **"Simpan draf terlebih dahulu sebelum finalisasi."**, tidak membuka dialog, dan memfokuskan tombol Simpan draf.

Setelah finalisasi berhasil, editor membaca ulang detail notula dari server sebelum menampilkan notula final. Dengan demikian hasil, PIC, jadwal, dan agenda yang terlihat pada halaman final adalah data yang benar-benar dikunci dalam transaksi finalisasi.

Regresi E2E A01 menjalankan: buat dan simpan draf valid → ubah hasil tanpa simpan → klik Finalisasi → pastikan dialog tidak terbuka dan fokus kembali ke Simpan draf → simpan → finalisasi → reload → pastikan hasil final adalah hasil terbaru yang tersimpan.

Run E2E pertama menemukan race pada test yang mengetik sebelum draf hasil simpan selesai dimuat ulang. Test diperbaiki dengan menunggu nilai server terlebih dahulu; run akhir lulus 4/4. Tidak ada perubahan database atau migration pada A01.
