# MOM-011 — Evidence notula dan tindak lanjut

Tanggal: 24 September 2026. Implementasi lokal tersedia; UAT pengguna NOT_RUN.

## Implementasi

- Supabase Storage bucket privat `evidence`, migration baru `20260924150000_mom_011_evidence.sql` diterapkan lewat `supabase migration up --local` tanpa reset/seed database aktif.
- Hak baca/unggah divalidasi server melalui RLS dan fungsi akses target; anggota nonaktif/anon ditolak. Draf privat untuk owner/admin. Task dapat diunggah PIC/owner/admin; anggota aktif membaca task/final. Task soft-deleted menolak akses evidence.
- File append-only: tidak dapat ditimpa/dihapus oleh akun aplikasi. Tercatat owner upload, nama pengunggah dan waktu server. Evidence final bersifat lampiran tambahan; isi notula final tidak berubah.
- PDF/JPEG/PNG/WebP/DOCX/XLSX maksimal 10 MiB. Pilihan file dipertahankan ketika unggah gagal; key yang sama dipakai saat retry. Unduh melalui sesi terautentikasi.
- Form notula baru memberi petunjuk simpan draf dahulu. Evidence task opsional, disimpan independen dari status DONE dan catatan.
- Detail action diperbaiki agar panel tidak overflow pada tablet/ponsel. Mock unit dashboard diperbarui untuk filter `deleted_at IS NULL` dari perubahan soft-delete sebelumnya; assertion memastikan filter diterapkan pada semua count.

## Cara mencoba

1. Buat dan simpan draf, pilih file pada **Evidence rapat**, lalu **Unggah evidence**. Uji unduh dan reload.
2. Finalisasi notula. Evidence rapat tetap dapat dibaca; owner/admin dapat menambah lampiran tanpa mengubah isi final.
3. Buka detail task sebagai PIC/owner/admin. Unggah pada **Bukti penyelesaian tindak lanjut**, lalu ubah status dan simpan catatan hasil seperti biasa.

## Batas implementasi

- Retensi append-only, belum ada hapus file, preview, antivirus, atau kewajiban evidence untuk DONE. Akses byte selalu mengikuti target dan status keanggotaan saat meminta unduh.
- File draf yang dihapus atau task yang dihapus lunak tetap tersimpan privat dan tidak dapat diakses melalui aplikasi. Pembersihan fisik operator memakai Storage API; tidak ada garbage collector otomatis.
- QA ini tidak mengklaim seluruh acceptance MVP atau persetujuan UAT. MOM-011 tetap IN_PROGRESS untuk handoff UAT/validasi menyeluruh.

Referensi implementasi: [Supabase Storage access control](https://supabase.com/docs/guides/storage/security/access-control), [ownership](https://supabase.com/docs/guides/storage/security/ownership), [bucket restrictions](https://supabase.com/docs/guides/storage/buckets/fundamentals).
