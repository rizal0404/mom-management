# MOM-008 — Redesign layout timeline dan task list

Tanggal: 24 September 2026 (WITA). Lingkup: presentasi `/actions`, mengikuti referensi pengguna dengan tema M3 hijau-lime existing.

## Perubahan

- Tab Timeline menampilkan panel jadwal di atas daftar task; tab Tabel menampilkan daftar task saja. Daftar tetap lintas pekan dan diberi keterangan eksplisit; timeline memakai overlap pekan existing.
- Toolbar segmented dan filter disclosure; seluruh filter URL, reset, pagination masing-masing panel, retry, dan detail tetap tersedia.
- Timeline lebih ringkas: grid harian, header sticky, penanda hari ini, bar beraksen status/jenis, PIC berupa avatar inisial, judul lengkap/jadwal dalam tooltip. Area timeline dapat discroll ketika data banyak.
- Daftar memakai header panel, tabel kompak, kolom judul di depan, avatar PIC dan badge existing. Ponsel memakai agenda dan kartu.
- Loading daftar menyembunyikan row lama; error/empty ditempatkan dalam panel daftar.
- Tidak mengubah service, migration, aturan akses, atau data operasional. E2E menggunakan fixture DATA DEMO di Supabase lokal; database tidak direset karena berisi data sesi pengguna juga.
